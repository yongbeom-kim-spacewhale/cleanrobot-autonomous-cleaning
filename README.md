# CleanRobot — 공원 환경 미화 로봇

공원을 자율 순찰하며 벤치와 테이블의 쓰레기를 탐지·수거·분류하고 복귀하는 Isaac Sim 기반 로봇 시스템입니다.

[시연 영상](https://drive.google.com/file/d/17ddWwwEUw1dHVDRcB6FfFW53TnRAwtuX/view)

## 프로젝트 정보

- 기간: 2026.07.29–2026.08.12
- 인원: 5명
- 역할: PM·팀장, 전체 흐름·요구사항, 로봇 모델과 공원 환경 구현
- 기술: ROS 2, Isaac Sim, Nav2, YOLO Segmentation, Doosan M0609, RealSense D455, LiDAR

## 담당 범위

- 자율 이동→탐지→정렬·접근→작업 인계→수거·분류→다음 지점 또는 Home 복귀 흐름 설계
- CleanRobot USD 모델, 로봇팔·그리퍼·적재함·카메라·전후방 LiDAR 구성
- 공원 에셋 배치, collision, 금지구역과 수거 지점·이동 순서 설계
- 매일 진행 상황 확인, 문제 원인 공동 분석과 대안 전환 관리
- 학습 데이터 색상 편중과 투명·반사 재질 문제 발견 및 수정 방향 제시

Occupancy Map, YAML, 웨이포인트 코드와 Costmap TF 해결은 다른 팀원이 담당했습니다.

## 성능 개선

초기 자체 이동 모델은 센서·카메라 부하로 약 8FPS였습니다. Nova Carter 기반으로 모델을 다시 구성하고 불필요한 센서와 카메라를 제거해 22FPS까지 높였습니다. 맵과 추가 설정을 조정한 최종 영상에서 약 28FPS 순간값을 확인했습니다.

## 결과

- 두 수거 지점의 3개 물체를 탐지·접근·수거하고 Home으로 복귀하는 통합 시연 완성
- Isaac Sim 실행 성능 약 8FPS → 22FPS, 후속 설정 후 영상 기준 약 28FPS
- train/test 색상 편중 수정 후 팀 모델의 과도한 오탐 감소
- 팀 AI 결과: Mask mAP50-95 86.48% → 89.44%, 최종 Mask mAP50 97.96%

약 28FPS는 평균값이 아닌 영상의 근사 순간값이며, AI 수치는 담당 팀원의 재학습을 포함한 팀 결과입니다.

## 범위 관리와 개선 방향

초기 약 16개 쓰레기를 2개 지점·3개 물체로 줄여 핵심 흐름의 통합 완성도를 우선했습니다. 향후 로봇팔의 길이와 장착 위치를 조정해 작업공간을 넓히고, 변경된 기구 구조에 맞춰 파지 알고리즘을 함께 최적화할 계획입니다.
